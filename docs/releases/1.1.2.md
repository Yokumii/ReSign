## 版本说明

ReSign 1.1.2 扩展了对各类标准 iOS App Extension 的签名与生命周期支持，并引入 App Groups 动态映射与运行时兼容机制，解决共享组跨团队占用无法使用的问题。

### 新增功能

- 支持包含各类标准 `NSExtension`（分享、Action、WidgetKit、通知服务／内容、自定义键盘、照片编辑、Intents 等）的单层 App Extension 导入与重签。
- 支持主应用 `UIApplicationShortcutWidget` 对内嵌 Widget 的 Bundle ID 引用同步更新。
- 支持 App Groups 动态映射：当原共享组无法在当前开发者团队直接注册时，自动生成团队专属映射组（`group.io.resign.<团队 ID>.<原组名摘要>`）并申请描述文件授权。
- 引入 `ReSignAppGroups.framework` 运行时兼容库：在重签名时通过 Mach-O 动态注入，自动重定向 `NSFileManager` 共享容器与 `NSUserDefaults` suite 访问，无需手动修改应用二进制。
- 允许导入扩展与主应用版本号不一致的 IPA，签名时自动将各扩展版本同步为主应用版本。

### 工程改进

- 优化 Mach-O 可执行文件注入器，利用现有头部填充安全插入加载命令，避免改变节偏移与符号地址。
- 重签名时严格校验扩展所需的额外权限，对未获授权的关键权限明确报错，避免权限静默丢失。
- 增加 App Extension 混合导入、Widget 引用重写、版本同步以及 App Groups 动态映射与 Mach-O 注入测试。

### 验证状态

Action、WidgetKit、通知、自定义键盘、照片编辑及 Intents 等扩展的安装、调用与覆盖续签已完成真机验证。
非分享扩展的 App Groups 通信、额外能力授权、主应用与扩展版本不同 IPA 的同步，以及原共享组映射后的容器与 UserDefaults 共享已完成真机验证。

IP 直连错误设备拒绝、地址动态变更、长时间传输心跳中断恢复以及到期失败退避流程仍待验证。

### 限制

仅支持单层 App Extension，不处理 ExtensionKit 格式扩展、嵌套扩展、WatchKit 扩展或 App Clip。共享组兼容库仅适配通过标准 Foundation 接口访问共享容器与 UserDefaults 的场景。
