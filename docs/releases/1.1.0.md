## 版本说明

ReSign 1.1.0 增加 DMG 安装镜像、应用图标和局域网直连能力，并改为随应用构建固定版本的设备通信库。

### 新增功能

- 应用列表显示从 IPA 提取并缓存的主应用图标。
- 发布附件改为包含“应用程序”快捷方式的 DMG 安装镜像。
- 自动发现已配对的 USB 或局域网设备，双通道在线时优先使用 USB。
- 在校园网等无法组播自动发现的网络中，可通过设备 IP 直接连接、传输 IPA 和安装应用。
- IP 直连保存到设备记录，支持 IPv4 和可路由的 IPv6 地址；连接时校验设备身份和配对证书，并在传输期间维持无线心跳。

### 工程改进

- libimobiledevice 1.4.0 的所需源码固定为内置动态库 `ReSignMobileDevice`，随项目源码和许可证一起分发。
- 扫描与安装、IP 地址修改互斥，避免无线连接和手动地址操作相互干扰。
- 增加 IP 地址校验、旧资料兼容、地址持久化和连接状态显示测试。

### 验证状态

手机热点局域网连接、校园网 IP 直连、心跳维持、IPA 传输和手动续签安装已完成真机验证。

临近到期自动续签、心跳中断恢复、错误设备拒绝、地址变化和 USB／局域网双通道切换仍待验证。

### 限制

IP 直连要求设备已通过 USB 配对，并使用数值单播地址；不支持主机名、端口、带作用域的 IPv6 链路本地地址或整段网络扫描。网络访问控制仍需允许配对、心跳、文件传输和安装服务端口。
