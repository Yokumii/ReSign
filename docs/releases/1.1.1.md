## 版本说明

ReSign 1.1.1 增加对带有分享扩展（Share Extension）的 IPA 签名的支持，并完善了 App Groups 共享组授权与多组件独立签名流程。

### 新增功能

- 支持导入包含 `com.apple.share-services` 分享扩展的 IPA。
- 为主应用与分享扩展分别生成稳定的 Bundle ID 并独立配置描述文件。
- 支持应用声明的 App Groups 共享组在当前开发团队中自动注册与授权，保证主应用与分享扩展间的数据通信。
- 自动续签以证书及所有组件描述文件中最早到期时间为准进行统一调度。

### 工程改进

- 严格校验扩展与主应用版本号一致性，限制仅支持顶层分享扩展，拒绝嵌套插件及未授权组件。
- 统一 Mach-O 权限读取逻辑，扩展权限仅匹配对应扩展目录与可执行文件，防止扩展权限泄漏至内嵌 Framework 或动态库。
- 增加分享扩展 Bundle ID 映射、加密检查、版本一致性及 App Groups 权限相关的自动化测试。

### 验证状态

分享扩展的多组件签名、安装、分享面板调用与覆盖续签，以及 App Groups 共享容器通信已完成真机验证。
同时完成了 USB／局域网双通道去重与 USB 优先、设备重连发现与任务恢复、以及临近到期自动续签验证。

IP 直连错误设备拒绝、地址动态变更、长时间传输心跳中断恢复以及到期失败退避流程仍待验证。

### 限制

仅支持单层分享扩展（Share Extension），不支持 Action Extension、WidgetKit 等其他类型扩展或嵌套扩展。若原应用声明的 App Group 已被其他开发团队占用，由于 Apple 限制无法跨团队注册同名共享组，需更换开发团队或重新构建应用。
