## 版本说明

ReSign 1.1.4 新增 IPA 软件源自动识别与定时更新能力，按 macOS 27 Liquid Glass 语言重构应用界面并支持应用内深浅色外观切换，同时完善项目工程化与自动化质量校验体系。

### 新增功能

- **软件版本自动更新**：导入 IPA 时自动扫描包内配置与二进制以识别更新来源，支持 GitHub Releases 与 AltStore JSON 软件源，支持附件通配符匹配与钥匙串存储的 GitHub Token。
- **单份回滚保护**：定时或手动下载新版 IPA 前校验大小、SHA-256、原始 Bundle ID、系统版本兼容性及防降级规则；新版安装成功前保留上一份 IPA，支持随时回滚并暂停自动更新。
- **macOS Liquid Glass 界面改造**：统一采用原生 Liquid Glass 按钮、分组表单、边缘柔和滚动效果与 `safeAreaBar` 弹窗结构。
- **主题外观切换**：在设置中支持“跟随系统／浅色／深色”三态切换与实时预览，并优化浅色与深色模式下的卡片、边框与警告对比度。

### 问题修复

- 修复应用卡片更多菜单按钮间距、软件更新来源占位符显示及登录项开关失败回滚清空报错的问题。
- 将设置与登录弹窗报错改为内联展示，允许在首次签名安装期间保存更新来源，补齐设备扫描期间的按钮禁用与快捷键保护，并规范化登录邮箱与双重认证验证码输入。

### 工程改进

- 新增面向 AI Coding 与开发者的项目规范文档（`AGENTS.md` / `CLAUDE.md`、`DESIGN.md`、`docs/ARCHITECTURE.md`）。
- 新增 `Makefile`、`scripts/check.sh`、`scripts/check-consistency.py`、`.swift-format` 与 `.githooks/pre-commit`，在本地与 CI 自动校验设计令牌、版本号、固定依赖、脚本语法及编码卫生。
- 新增 PR 模板、GitHub Actions Dependabot 配置与编辑器配置。

### 验证状态

前期遗留的 4 项真机场景（IP 直连错误设备身份／证书拒绝路径、IP 地址变更／清除与重启恢复、IP 直连长时间传输与心跳／互斥清理、到期自动续签失败退避与恢复）均已于 2026-11-28 完成真机验证并通过，详见 [docs/TESTING.md](../../docs/TESTING.md)。
