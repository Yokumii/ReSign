## 版本说明

首个公开版本，包含完整的 Apple 账号登录、IPA 重签、USB 安装和自动续签流程。

### 功能

- Apple 开发者账号登录、双重认证和开发团队选择。
- 自建 Anisette v3 服务配置，认证请求由客户端直接发送给 Apple。
- USB 设备发现、历史设备记录、IPA 导入和稳定的签名 Bundle ID。
- 开发证书、设备、App ID 和描述文件管理。
- IPA 重签、首次安装及同一应用的版本覆盖更新。
- 启动、Mac 唤醒、设备连接恢复和定时任务触发的续签检查。
- 钥匙串保存认证会话和签名私钥，本地资料原子写入。

### 验证状态

真实账号登录、证书与描述文件申请、首次签名安装和启动、ReSign 重启恢复，以及不同版本覆盖安装后的数据保留已完成真机验证。

设备物理重连后的任务恢复、临近到期自动续签及有效期延长、自动续签失败后的恢复流程尚未完成真机验证。

### 限制

仅支持普通、未加密 IPA；不支持应用扩展、Watch 应用、App Clip、符号链接和特殊文件。当前为单账号和 USB 连接方式，应用图标使用占位符。
